API Overview

The Drive API is a secure file sharing platform that allows users to upload files, create time-limited exposures, and manage access requests with advanced security features.

Key Features

🔐 Authentication

Phone-based registration with secure JWT tokens. No passwords required - just your phone number and a unique login hash.

📁 File Management

Upload, organize, and manage files with automatic MIME type detection and secure storage.

🔗 Smart Exposures

Create time-limited public links with granular permissions (read-only or download).

✅ Access Control

Approve or deny access requests with IP tracking and automatic blacklisting for security.

User Types

Free Users

• One file exposure at a time
• Maximum 5-minute exposure duration
• Basic access controls

Premium Users

• Unlimited file exposures
• Up to 24-hour exposure duration
• Advanced analytics and controls

Quick Start Guide

Get your application connected to the Drive API in just a few steps:

  1. Register a User: Create an account with a phone number
  2. Authenticate: Login to receive your JWT access token
  3. Upload Files: Store files securely in your account
  4. Create Exposures: Generate shareable links with time limits
  5. Manage Access: Approve or deny access requests
# 1. Register a new user POST /auth/register Content-Type: application/json { "phone": "+918043652258" } # 2. Login with received login_hash POST /auth/login Content-Type: application/json { "phone": "+918043652258", "login_hash": "abc123def456..." } # 3. Upload a file POST /files/upload Authorization: Bearer your_jwt_token Content-Type: multipart/form-data # 4. Create exposure for sharing POST /expose/file Authorization: Bearer your_jwt_token Content-Type: application/json { "file_id": 1, "permission": "download", "expires_minutes": 30 }

API Endpoints

Authentication

POST /auth/register
POST /auth/login

Secure phone-based authentication system.

File Management

POST /files/upload
GET /files/list
GET /files/download/{id}
DELETE /files/delete

Complete file lifecycle management.

File Exposure

POST /expose/file
GET /expose/list
GET /expose/info/{hash}
DELETE /expose/file/{hash}

Create and manage file exposures.

Access Management

POST /access/request
GET /access/view/{hash}
GET /access/download/{hash}

Request and access shared files.

Approval System

GET /approve/pending
POST /approve/decision
GET /approve/history

Manage access requests and history.

Utilities

GET /health
GET /docs

System health and documentation.

Code Examples

JavaScript/Node.js

// Register and login const registerUser = async (phone) => { const response = await fetch('/auth/register', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON. ify({ phone }) }); return response.json(); }; const loginUser = async (phone, loginHash) => { const response = await fetch('/auth/login', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ phone, login_hash: loginHash }) }); return response.json(); }; // Upload file const uploadFile = async (file, token) => { const formData = new FormData(); formData.append('file', file); const response = await fetch('/files/upload', { method: 'POST', headers: { 'Authorization': `Bearer ${token}` }, body: formData }); return response.json(); };

Python

import requests # Register user def register_user(phone): response = requests.post('/auth/register', json={'phone': phone}) return response.json() # Upload file def upload_file(file_path, token): with open(file_path, 'rb') as f: files = {'file': f} headers = {'Authorization': f'Bearer {token}'} response = requests.post('/files/upload', files=files, headers=headers) return response.json() # Create exposure def create_exposure(file_id, token, expires_minutes=30): data = { 'file_id': file_id, 'permission': 'download', 'expires_minutes': expires_minutes } headers = {'Authorization': f'Bearer {token}'} response = requests.post('/expose/file', json=data, headers=headers) return response.json()
