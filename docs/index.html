API Overview

The Drive API is a secure file sharing platform that allows users to upload files, create time-limited exposures, and manage access requests with advanced security features.

Key Features

🔐 Authentication

Phone-based registration with secure JWT tokens. No passwords required - just your phone number and a unique login hash.

📁 File Management

Upload, organize, and manage files with automatic MIME type detection and secure storage.

🔗 Smart Exposures

Create time-limited public links with granular permissions (read-only or download).

✅ Access Control

Approve or deny access requests with IP tracking and automatic blacklisting for security.

👑 Premium Sharing

Phone-based sharing with secure tokens, download limits, and advanced recipient management.

⚡ Health Monitoring

System health checks and API status monitoring for reliable service operation.

User Types

Free Users

• One file exposure at a time
• Maximum 5-minute exposure duration
• IP-based access control
• Manual approval system

Premium Users

• Unlimited file exposures
• Up to 24-hour exposure duration
• Phone-based sharing
• Secure token system
• Download limits per recipient

Quick Start Guide

Get your application connected to the Drive API in just a few steps:

⚠️ File Download Testing: File download endpoints should not be tested directly in Swagger UI as it may corrupt binary files. Use a proper HTTP client (Postman, curl, or browser) for downloading files.
  1. Register a User: Create an account with a phone number
  2. Authenticate: Login to receive your JWT access token
  3. Upload Files: Store files securely in your account
  4. Create Exposures: Generate shareable links with time limits
  5. Manage Access: Approve or deny access requests (free) or share directly (premium)

File Management

POST /files/upload

Code Examples

JavaScript/Node.js

// Register and login const registerUser = async (phone) => { const response = await fetch('/auth/register', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ phone }) }); return response.json(); }; const loginUser = async (phone, loginHash) => { const response = await fetch('/auth/login', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ phone, login_hash: loginHash }) }); return response.json(); }; // Premium: Create phone-based exposure const createPremiumExposure = async (fileId, phones, token) => { const response = await fetch('/premium/expose', { method: 'POST', headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'application/json' }, body: JSON.stringify({ file_id: fileId, permission: 'download', expires_minutes: 720, shared_with_phones: phones, max_downloads_per_recipient: 3 }) }); return response.json(); }; // Premium: Access file with token const accessPremiumFile = async (accessToken, phone) => { const response = await fetch( `/premium/access/${accessToken}?phone=${encodeURIComponent(phone)}` ); return response.json(); };

Python

import requests # Register user def register_user(phone): response = requests.post('/auth/register', json={'phone': phone}) return response.json() # Upgrade to premium def upgrade_to_premium(token): headers = {'Authorization': f'Bearer {token}'} response = requests.post('/auth/upgrade-premium', headers=headers) return response.json() # Create premium exposure def create_premium_exposure(file_id, phones, token): data = { 'file_id': file_id, 'permission': 'download', 'expires_minutes': 720, 'shared_with_phones': phones, 'max_downloads_per_recipient': 5 } headers = {'Authorization': f'Bearer {token}'} response = requests.post('/premium/expose', json=data, headers=headers) return response.json() # Access premium file def access_premium_file(access_token, phone): params = {'phone': phone} response = requests.get(f'/premium/access/{access_token}', params=params) return response.json()
